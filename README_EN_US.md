## About

Bawa Launcher lets you play Minecraft: Java Edition on Android. It has a clean iOS-inspired look with translucent "liquid glass" cards and rounded corners.

## Features

- Minecraft: Java Edition on Android
- Mod and resource pack management
- Microsoft account login and local (offline) login
- Liquid-glass interface
- Developer page with social links and a donate QR code

## Build

1. Open the project in Android Studio.
2. In `ZalithLauncher/gradle.properties`, set your own `oauth_client_id` (Microsoft login) and `curseforge_api_key` (mod search).
3. Add your own signing key and passwords for release builds.
4. Run `./gradlew assembleDebug`.

## Support

If you like Bawa Launcher, scan the donate QR code in **Settings → About → Developer**.
